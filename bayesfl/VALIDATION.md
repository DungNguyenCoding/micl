# Validation entry point

Current release results and environment limits are in
[docs/wireless/VALIDATION.md](docs/wireless/VALIDATION.md) and `validation/wireless/`.
The available suite and synthetic checks are not a physical radio experiment, full
MNIST/CIFAR wireless benchmark or target CUDA/Flower/Ray certification.

Preserved historical validation files are under docs/history/. Do not repeat their old
13/23/110-test counts as current-server results. Run the documented test commands in the
existing research environment, inspect dependency skips and record the actual outcome.
